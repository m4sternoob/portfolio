Stumble Lite — Technical Deep Dive

Architecture

  • Single GameViewController owns SCNView, scene, players, obstacles
  • SCNSceneRendererDelegate drives 60 FPS fixed-timestep update loop
  • SCNPhysicsContactDelegate handles kill-zone elimination via bitmask filtering
  • 100% programmatic UIKit — no storyboards, no SwiftUI, no xibs

Core Systems

Player3D
Capsule physics body + sphere head + eye nodes. Custom bitmask categories. Force-based movement with horizontal speed capping.
Obstacle3D
Kinematic bodies — spinning bars (angular velocity), moving platforms (sinusoidal position). Update in render delegate.
JoystickView
Touch-drag virtual stick, outputs normalized CGVector. Dead zone, magnitude clamping, screen-to-world transform.
Physics.swift
Bitmask categories (Player, Wall, KillZone), collision/contact test masks. Clean separation of concerns.

Build Pipeline

  • gen_pbxproj.py generates .xcodeproj from source tree
  • Post-gen fix: truncate -s -2 + append } for valid pbxproj
  • Scheme: StumbleLite.xcscheme in shared schemes dir
  • Bundle ID: com.example.StumbleLite · Deployment: iOS 16.0 (iPhone X+)

Planned Polish

  • Bot AI for non-local players (wander + avoidance)
  • Multiple arena variants / map rotation
  • Squash/stretch on impact, screen shake, particle bursts
  • Character variety — skins, trail effects, emotes

Phone Mirror + Agent Pipeline

Problem

Wireless adb debug port on Pixel changes randomly. Every scrcpy session required manual adb connect IP:NEW_PORT — a friction multiplier that broke flow.

Solution

  • Local OpenClaw agent monitors adb devices output on interval
  • On port change detection, auto-runs adb connect IP:NEW_PORT
  • AppleScript bridge triggers scrcpy relaunch with new connection
  • Zero manual steps — phone mirrors instantly, every time

Stack

scrcpy
Genymobile — high-performance screen mirroring
adb
Android platform-tools — device communication
OpenClaw
Local agent (MiniMax Portal) — monitoring + orchestration
AppleScript
macOS integration — app launch/focus automation

Impact

Eliminated a recurring friction step from every phone-screen session. Compound time savings across development, testing, and demo workflows.
