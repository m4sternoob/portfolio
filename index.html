Stumble Lite — Technical Details

Architecture

  • Single GameViewController owns SCNView, scene, players, obstacles
  • SCNSceneRendererDelegate drives 60 FPS update loop
  • SCNPhysicsContactDelegate handles kill-zone elimination
  • No storyboards / SwiftUI — 100% programmatic UIKit

Systems

  • Player3D: Capsule body + sphere head + eye nodes, physics body with custom bitmasks
  • Obstacle3D: Kinematic bodies — spinning bars, moving platforms with sinusoidal motion
  • JoystickView: Touch-drag virtual stick, outputs normalized CGVector
  • Physics.swift: Bitmask categories (player, wall, killZone), collision filtering

Build Pipeline

  • gen_pbxproj.py generates .xcodeproj from source tree
  • Post-gen fix: truncate -s -2 + append } for valid pbxproj
  • Scheme: StumbleLite.xcscheme in shared schemes
  • Bundle ID: com.example.StumbleLite
  • Deployment target: iOS 16.0 (iPhone X compatible)

Polish (Planned)

  • Bot AI for non-local players
  • Multiple maps / arena variants
  • Squash/stretch on impact, screen shake, particles
  • Character variety (skins, trail effects)

Phone Mirror + Agent Pipeline

Problem

Wireless adb debug port on Pixel changes randomly. Every scrcpy session required manual adb connect IP:NEW_PORT — friction multiplier.

Solution

  • Local OpenClaw agent monitors adb devices output
  • On port change, auto-runs adb connect IP:NEW_PORT
  • AppleScript bridge triggers scrcpy relaunch
  • Zero manual steps — phone mirrors instantly

Stack

  • scrcpy (Genymobile)
  • adb (platform-tools)
  • OpenClaw agent (local, MiniMax Portal)
  • AppleScript for macOS integration

Built with vanilla HTML/CSS/JS — no framework bloat. Last updated September 2026.
